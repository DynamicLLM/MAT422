# Representative Codex Prompt: Model Selection

> Based on the problem specification and data types, propose at least two reasonable binary-classification models. For each model, state the assumptions, strengths, limitations, and why it may fit the problem. Recommend a primary model and a comparison model. Do not choose a model only because it is easy to code.

## Expected evidence

The final project should preserve the actual Codex response used for the model-selection decision and explain what the student accepted, rejected, or modified.
