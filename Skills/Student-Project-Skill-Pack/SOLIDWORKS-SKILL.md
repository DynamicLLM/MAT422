# SOLIDWORKS Modeling Skill
Given a function/target geometry, materials, loads, manufacturing conditions, and constraints, develop and improve a parametric CAD design.

Workflow: requirements → design variables → initial parametric model → evaluation → optimization → revised model → validation.

Prefer SOLIDWORKS API or add-in/plugin; file exchange is acceptable when sufficient; GUI automation is fallback.

Variables may include thickness, width, height, hole diameter, fillet radius, material, spacing, and feature parameters. Objectives may include mass, material cost, manufacturing complexity, deformation, or other performance criteria subject to strength, geometry, safety, and manufacturing constraints.

Evidence: parametric model, variables, constraints, evaluation, optimization method, initial/final comparison, and appropriate CAD files.
