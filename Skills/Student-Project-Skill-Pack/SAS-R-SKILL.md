# SAS / R Statistical Modeling Skill
Given data and a statistical question, select a defensible model, estimate parameters, perform diagnostics, and compare alternatives.

Inspect data/variable types; match methods to question/assumptions; implement in SAS or R; run diagnostics/validation; compare alternatives; report uncertainty/limitations.

Evidence: rationale, diagnostics, validation, final code, reproducible output.
