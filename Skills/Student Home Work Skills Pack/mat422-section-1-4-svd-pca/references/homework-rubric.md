# MAT 422 Homework Rubric Reference

Use this rubric when creating or revising MAT 422 homework notebooks.

## Criteria

- Code Accuracy and Completeness, 20%: Python code should run without errors and demonstrate all required math concepts.
- Math Concept Coverage, 20%: The assignment should cover all key math concepts for the section and show clear understanding.
- Examples Appropriateness, 20%: Examples should be relevant and illustrate the math concepts effectively.
- Explanation and Documentation, 20%: Clear, concise explanations should accompany code and make the math and programming concepts easy to understand.
- GitHub Submission and Colab Functionality, 10%: Code should be saved directly from Colab to GitHub, and `Open in Colab` should be visible and functioning on GitHub.
- Submission Format and Clarity, 10%: Homework should be clearly formatted with readable code, explanations, and logical flow.

## Practical implications

- Never omit the required Colab badge.
- Do not produce code-only notebooks; every section needs explanatory markdown.
- Include numeric verification cells so code accuracy is visible.
- Include a final checklist that matches the grading categories.
