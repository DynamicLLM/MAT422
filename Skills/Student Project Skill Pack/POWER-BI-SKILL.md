# Power BI Business Analytics Skill
Turn a business problem/dataset into an analytical model, dashboard, and recommendation.

Use available Power Query, DAX, Python-assisted analysis, and structured file/data exchange. Direct API automation is optional and must not be assumed available to every student.

Workflow: problem → objectives/constraints → preparation → analytical model → forecast/segmentation/analysis → Power BI dashboard → validation → recommendation.

A file-based workflow is acceptable; e.g., Codex/Python generates a validated CSV/Excel output imported into Power BI. Document what occurred inside vs. outside Power BI.
