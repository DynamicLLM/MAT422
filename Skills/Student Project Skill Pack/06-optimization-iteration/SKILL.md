# Optimization and Iteration Skill
Define an objective/comparison criterion; identify adjustable parameters/design variables; select an optimization/search strategy; generate candidates; evaluate them in the chosen software; retain feasible solutions; compare quantitatively; stop using a defensible criterion.

Examples: SOLIDWORKS—minimize mass subject to strength/displacement constraints. MATLAB—minimize error/maximize predictive performance. SAS/R/Stata—compare/tune specifications under validation criteria. Power BI—improve forecast/decision metric. ML—tune hyperparameters without compromising validation.

Deliverable: initial-vs-improved comparison with objective, constraints, method, and measurable improvement.
