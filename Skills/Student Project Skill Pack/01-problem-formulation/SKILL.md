# Problem Formulation Skill
Turn a real-world problem from the student's major into a precise computational/modeling problem.

Student provides: context; objective; available data, geometry, materials, or inputs; assumptions/conditions; constraints; expected outputs; quantitative success criteria.

Agent: restate precisely; identify missing information; do not invent critical requirements; separate objectives from constraints; identify decision variables/inputs/outputs; define measurable success criteria.

Deliverable: concise problem specification for the next skill.
