# MATLAB Modeling Skill
Given data or a computational problem, determine an appropriate model under student-specified conditions and use MATLAB to implement, evaluate, and improve it.

Workflow: data/problem → candidate models → selection → MATLAB implementation → validation → optimization/tuning → final model.

Examples: regression/parameter estimation, PCA, SVM/classification, neural networks, optimization, numerical simulation, dynamical/physical modeling.

Use MATLAB code directly or MATLAB Engine/API when external automation is appropriate. Explain model choice, show validation, and document iterations.
