# Physics Modeling Skill
Given observations, physical conditions, or an established relationship, formulate a quantitative model and compare it with observations.

Workflow: physical problem → equations/model candidates → parameter estimation → MATLAB/Mathematica → simulation/fit → validation → refinement.

Evidence: physical assumptions, equations, estimated parameters, computational method, data comparison, limitations.
