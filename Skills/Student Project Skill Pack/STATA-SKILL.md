# Stata Econometrics Skill
Given an economic question, dataset, assumptions, and criteria, develop/evaluate an econometric model.

Define variables; state identification assumptions for causal claims; select candidate specifications; generate reproducible Stata code; run robustness/diagnostics; compare specifications; separate prediction from causal claims.

Evidence: question, specification, assumptions, Stata code, diagnostics/robustness, interpretation.
