# Validation and Verification Skill
Check as applicable: mathematical/statistical correctness; data quality/leakage; assumptions; numerical stability; cross-validation/generalization; engineering constraints; physical plausibility; reproducibility; software errors; required thresholds.

Deliverable: validation table listing each requirement, evidence, result, and pass/fail or quantitative assessment.

Always distinguish verified results from assumptions or unverified claims.
