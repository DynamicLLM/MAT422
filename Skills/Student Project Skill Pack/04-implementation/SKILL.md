# Software Implementation Skill
Generate/modify code, scripts, API calls, plugin code, or structured files as appropriate. Keep implementation modular and reproducible. Explain important generated operations. Record software version/packages/toolboxes. Provide repeatable execution steps. Never claim successful execution unless observed.

Students run software when necessary, inspect errors/outputs, verify correspondence with the specification, and preserve final code/scripts/files.

Deliverable: reproducible implementation package and execution note.
