# Interface Selection Skill
Priority: 1) native API, 2) plugin/add-in, 3) scripting/programming interface, 4) CLI, 5) structured file/data exchange, 6) GUI automation.

Identify what the software exposes; choose the simplest reliable mechanism; explain what it can/cannot control; prefer deterministic interfaces; use file exchange when sufficient; treat GUI automation as a fallback and document limitations.

Deliverable: interface plan with software/environment, inputs, outputs, and limitations.
