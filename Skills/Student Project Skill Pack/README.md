# MAT 422 Student Project Skill Pack

Common Codex workflow for discipline-specific modeling projects.

## Required workflow
1. Problem formulation
2. Model/method selection
3. Interface selection
4. Software implementation
5. Validation and verification
6. Optimization and iteration
7. AI critique
8. Documentation

## Interface options
Prefer the strongest practical machine-actionable interface: API; plugin/add-in; scripting/programming interface; CLI; structured file/data exchange; GUI automation as a fallback.

A formal API is not mandatory. Students must demonstrate meaningful programmatic or data-driven interaction with the selected professional/computational software.

## Software tracks
Engineering: SOLIDWORKS/NX. Mathematics: MATLAB/Mathematica. Statistics: SAS/R. Economics: Stata. Business analytics: Power BI. Physics: MATLAB/Mathematica. CS/ML: Python with scikit-learn, PyTorch, TensorFlow, or similar frameworks.

The student defines the problem, objectives, requirements, data/inputs, and constraints. The AI agent assists with model/method selection and implementation. The software executes the task. Results are evaluated against the requirements and iteratively improved. The student remains responsible for domain judgment, verification, and final conclusions.
