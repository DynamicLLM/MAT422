# Model / Method Selection Skill
Examine the problem, data, objectives, and constraints. Identify candidate methods; explain assumptions/limitations; recommend a primary method and useful alternatives; state comparison evidence; do not select a method only because it is easy to execute.

Examples: MATLAB—regression, PCA, optimization, SVM, neural networks, numerical models. SAS/R—statistical models and diagnostics. Stata—econometric specifications. SOLIDWORKS/NX—geometry, material, dimensions, features, design parameters. Power BI—transformations, measures, forecasts, visualizations. Python ML—features, algorithms, architectures, validation.

Deliverable: justified selection record with alternatives and criteria.
